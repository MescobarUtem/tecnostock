# TecnoStock - Sistema de Inventario
Sistema web desarrollado en PHP (PDO) y MySQL, con control de acceso por roles (RBAC) y validaciones de seguridad.

## Instalación
1. Clonar este repositorio en la carpeta `htdocs` (XAMPP).
2. Crear una base de datos llamada `tecnostock` e importar el archivo `tecnostock.sql`.
3. Ejecutar en el navegador: `http://localhost/tecnostock`
